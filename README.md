<h1 align="center">补习班教务管理系统</h1>

<p align="center">
  一个面向中小型培训机构的 AI 教务管理平台，融合课程排课、考勤成绩、教学驾驶舱、课程健康度、学生风险预警与 DeepSeek 智能分析，让机构运营和学生学情一目了然。
</p>

---

## 功能概览

- **用户认证** — 登录/注册，支持管理员与普通员工角色
- **学生管理** — 学生档案（姓名、年级、电话、备注），支持初中/高中六档
- **教师管理** — 教师档案与任教学科关联
- **教室管理** — 教室类型（大教室、小教室、自习室）与容量
- **课程管理** — 排课支持周一至周日、五个时段，自动检测教室/时间冲突
- **学生选课** — 关联学生到课程，大班小班灵活分配
- **考勤管理** — 按课程按日记录出勤/缺勤，支持考勤报表导出
- **课表调整** — 临时调课、换教室，保留原排课记录

- **成绩管理** — 记录学生在校考试和补习班小测验成绩，区分考试类型
- **数据分析** — 考勤率统计、成绩分布、分科对比、趋势图表；学校成绩覆盖全部在校科目（不限于补习科目）
- **文理分科** — 高中学生区分文科/理科，高二高三仅记录本方向科目成绩，选科口径与高考一致
- **择校冲刺分析** — 内置 2026 年苏州中考 / 江苏高考分数线（苏州高中录取线、指标生线、本科线、特招线，
  以及全国主要高校 2026 年在江苏的本科批投档线，历史类/物理类），
  按年级分阶段（初中基础期/中考冲刺期/高中基础期/高中提升期/高考冲刺期）估算中考/高考总分，
  自动匹配“冲刺/稳妥/保底”学校并给出分科提分空间与学习建议
- **AI 择校冲刺报告** — 结合 DeepSeek 生成个性化升学冲刺报告；AI 不可用时自动降级为规则引擎报告
- **教学驾驶舱** — 仪表盘聚合机构规模、今日课程、周负载、时段负载、教室占用、分科表现与趋势图
- **课程健康度** — 综合出勤率、得分率、满员率、教师课量计算健康分并给出干预信号
- **学生风险预警** — 结合出勤、成绩趋势、近30天缺勤生成风险分与风险等级
- **学生雷达图** — 每位学生各学科成绩+出勤率双轴雷达可视化
- **AI 智能报告** — 接入 DeepSeek API，一键生成学生个性化分析报告（含总体评价、强弱项、建议），自动保存最新报告并支持导出 PDF
- **AI 教学助手** — 自然语言问答、机构运营体检、排课优化建议、课程健康与风险分析，全部基于当前数据库实时数据

## 技术栈

| 层级 | 技术 |

## 快速开始

### 方式一：Docker（推荐）

```bash
docker compose up -d
```

访问 `http://localhost:5000`。数据持久化在 `./data` 目录。

### 方式二：Windows 本地运行

**开发模式：**

```bash
# 终端 1 — 启动后端
cd backend
pip install -r requirements.txt
python launcher.py

# 终端 2 — 启动前端开发服务器
cd frontend
npm install
npm run dev
```

**打包为 exe（生产部署）：**

```bash
# 需先安装 PyInstaller
pip install pyinstaller
build.bat
```

构建完成后运行 `start.bat` 即可启动，浏览器会自动打开。

### 方式三：纯 Python 运行

```bash
cd backend
pip install -r requirements.txt
python launcher.py
```

后端会检测端口可用性（优先 5000，自动查找 5000–5010），并自动在浏览器中打开管理页面。

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `TUTORING_HOST` | `0.0.0.0` | 监听地址 |
| `TUTORING_PORT` | `5000` | 监听端口 |
| `TUTORING_DB` | `tutoring.db` | 数据库文件路径 |
| `DOCKER_ENV` | — | Docker 环境标识（容器内自动设置） |

> 端口说明：若本机 5000–5010 被 Windows 系统保留（常见于启用 Hyper-V/WSL 后，
> 5000 落在系统动态端口段内），程序会自动在 8000/8080/9000 等常用端口段继续查找可用端口，
> 并在浏览器中打开实际端口。也可用 `TUTORING_PORT` 手动指定端口；
> 前端开发模式下可用 `VITE_PROXY_TARGET=http://127.0.0.1:<端口>` 同步代理地址。

## 择校冲刺分析说明

- **分数线数据**：系统内置 2026 年苏州市六区普通高中录取线（四星/三星及其他、提前批、指标生控制线）
  与 2026 年江苏省高考控制线（本科线、特殊类型招生控制线）。高考分析对象为江苏考生，
  因此高校分数线为全国主要 985/211/双一流及热门高校 2026 年在江苏的本科批投档线（历史类/物理类），
  不局限于江苏省内院校；可在“数据分析 → 择校冲刺”页查看和增删维护。
- **成绩估算**：初三按苏州中考科目权重（语数英 130、物化 100、道法历史 50、体育 50）估算总分；
  高中按高考口径（语数外 150、选科各 100）按文/理方向估算；初一初二/高一高二按已有科目加权换算并给出参考位次。
- **阶段分析**：不同年级给出不同结论——初中打基础、初三中考冲刺、高一选科定位、高二定向提升、高三高考冲刺，
  每条建议结合该生具体分数与提分空间生成。
